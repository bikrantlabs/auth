## bikrantlabs/auth

The complete authentication solution for my other projects.

I am building this project because I see myself repeatedly building the "authentication" part in every single project.

While I may use pre-built solutions like `better-auth` or `supabase auth`, I would love to build the authentication service by myself.

I've tried my best to make this service as strong, scalable and reliable as my current knowledge allows, however, this might not be the right choice to use in production-grade systems 🙃.

The features this service provides are sufficient enough to build a good authentication infra; `email/password login`, `google login`, `2FA` and other auth related features.
